# 鉴权与会员内容

## 定位

- OAuth：提供稳定 API 授权（推荐）
- Cookie：提供网页会话权限（会员/限制直播常需要）

## 推荐模式

- `auto`（推荐）：OAuth 为主，Cookie 兜底。

## OAuth 配置流程（GUI）

1. 打开 `设置`。
2. 填 `client_id / client_secret / redirect_uri`。
3. 点击“打开授权页面”。
4. 授权后复制 `code`。
5. 回填后点击“用 Code 换 Token”。
6. 点击“校验 Token”。

## Cookie 配置流程

1. 导出 Netscape 格式 `cookies.txt`。
2. 设置里启用 Cookie。
3. 设置 Cookie 路径（默认 `cookies.txt`）。
