# 架构总览

## 应用划分

### apps/cli

- 入口：`apps/cli/main.go`
- 模块：`apps/cli/checker`、`apps/cli/scheduler`、`apps/cli/recorder`、`apps/cli/config`

### apps/gui

- 后端入口：`apps/gui/main.go`
- 应用桥接：`apps/gui/app.go`
- 核心模块：`apps/gui/pkg/*`
- 前端：`apps/gui/frontend/src/*`

## GUI 主链路

1. Scheduler 按 Cron 检查主播状态。
2. Checker 解析直播状态与真实流地址。
3. Recorder 使用 ffmpeg 长连接录制。
4. 状态通过 Wails 事件回推给前端。
5. 录制结果写入 `history.json`。

## 鉴权模型

- `auto`：OAuth + Cookie 自动协同
- `oauth`：仅 OAuth API
- `cookie`：仅 Cookie 会话

## 并发模型

- 每主播独立监控任务与录制进程。
- 删除/暂停/退出会清理对应任务与进程。
