# 运行与构建

## CLI

### 运行

```powershell
cd apps\cli
go run . --config config.yaml
```

### 构建

```powershell
.\scripts\build-cli.ps1
```

该脚本生成 CLI 主程序和服务器/CLI 使用的独立 worker。

## GUI

### 开发模式

```powershell
cd apps\gui
wails dev
```

### 后端编译检查

```powershell
cd apps\gui
go test ./...
```

### 前端构建检查

```powershell
cd apps\gui\frontend
npm ci
npm run build
```

### 正式构建

```powershell
.\scripts\build-gui.ps1
```

Windows GUI 输出到：

```text
apps/gui/build/bin/twitcasting-recorder-gui.exe
```

GUI 主程序包含内置 worker 模式，不需要额外附带
`recorder-worker.exe`。

## 依赖

- Go
- Node.js + npm
- Wails CLI
- FFmpeg / FFprobe（运行录制与媒体时长探测时需要）
