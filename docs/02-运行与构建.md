# 运行与构建

## CLI

### 运行

```powershell
cd apps\cli
go run . --config config.yaml
```

### 构建

```powershell
go build -o twitcasting-recorder.exe .
```

## GUI

### 开发模式

```powershell
cd apps\gui
wails dev
```

### 后端编译检查

```powershell
cd apps\gui
go test ./...
```

### 前端构建检查

```powershell
cd apps\gui\frontend
npm run build
```

## 依赖

- Go
- Node.js + npm
- Wails CLI
- ffmpeg
