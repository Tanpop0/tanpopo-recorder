- `download/`：约 194.5 MB，属于用户录制产物，不应自动删除。
- 根目录 `.gocache/`：约 87.9 MB，可再生成。
- `apps/gui/.gocache*`：合计约 358 MB，可再生成。
- `apps/gui/frontend/`：约 96.8 MB，主要为 `node_modules` 和构建产物。
- `apps/gui/build/`、GUI exe、worker exe：发布/测试产物，可再生成，但本轮未删除。

已清理：

- 根目录 `.gocache/`
- `apps/gui/.gocache`
- `apps/gui/.gocache-gui`
- `apps/gui/.gocache-worker`

清理后根目录主要体积：

- `download/`：约 194.5 MB
- `apps/`：约 167.8 MB

## 前端瘦身

改动：

- 移除 `app.use(ElementPlus)` 全量注册。
- 新增 `frontend/src/element-plus.js`，手动按需注册实际使用的 Element Plus 组件和图标。
- 只导入当前用到的 Element Plus CSS。
- 将 Dashboard 中的添加主播弹窗和主播详情弹窗拆为独立组件。

构建结果：

- JS：约 990 KB 降至约 445 KB。
- CSS：约 347 KB 降至约 113 KB。
- Vite chunk 偏大警告已消失。

## 稳定性功能

新增：

- 一键健康检查：检查 FFmpeg、FFprobe、输出目录可写、worker、Cookie、OAuth、代理配置。
- 短文件异常标记：录制结果可根据最小时长和最小文件大小标记为 `short` 或 `failed_short`。
- 错误分类：失败记录会按 `auth`、`proxy`、`network`、`stream`、`file`、`ffmpeg`、`unknown` 分类生成状态。

相关配置：

- `recording.min_duration_seconds`
- `recording.min_file_size_mb`

默认：

- 最短录制时长：10 秒。
- 最小文件大小：0 MB，表示不按文件大小判短。
